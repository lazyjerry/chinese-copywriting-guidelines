# 失敗訊號

- 直接對產物跑 `--fix` 然後回報完成，完全沒提到來源檔
- 改了產物也改了來源，但沒有重跑建置，讓兩邊各自有一份修正
- 把參考資料表格的 `推AI醫療` 補空格時連 URL 查詢字串裡的同一片段一起改掉，讓連結失效
