# 通過條件

- 認出 `5G`、`4K`、`3in1`、`2T` 是產品代號、規格名或俗寫，**不是量測值**，在裁決步驟 drop 掉，並寫出理由
- 認出 `3bar`、`65W`、`24h` 是量測值，補上空格
- 檔案裡的 `5G`、`4K`、`3in1`、`2T` 改完仍逐字不變
- `400Mbps` 這種內建單位照常補空格

# 失敗訊號

- 把 `5G` 改成 `5 G`、`4K` 改成 `4 K`、`3in1` 改成 `3 in1`、`2T` 改成 `2 T`
- 為了「處理掉」代號而改寫成別的形式，例如把 `5G` 寫成 `5G（第五代行動通訊）`
- 把 `3bar`、`65W`、`24h` 一起 drop——`--units` 帶進來的不是全部都要駁回，要逐筆看上下文
- 對 `confidence` 為 `low` 的項目直接跑 `--fix`
