# SDK 上手說明

## 安裝

在LeanCloud上，資料儲存是圍繞`AVObject`進行的。每個 AVObject 都包含了與 JSON 兼容的 key-value 對應的資料。

半邊有空格、半邊沒有一樣算錯：在 LeanCloud上，資料儲存是圍繞`AVObject` 進行的。

## 初始化

先到主控台申請一組 AppKey，貼進設定檔之後執行初始化。這一步大約要花3分鐘，網路狀況不好時可能拉長到10分鐘。若逾時請重試，重試上限是5次。

我們建議把金鑰放進環境變數，不要直接寫死在原始碼裡。CI環境可以透過 Secrets 注入，本機開發則用 dotenv 讀取。

## 常見問題

初始化失敗最常見的原因是版本不符。請確認 SDK 版本在2.0以上，Node 版本在18以上。舊版的 Node12 已經停止支援，繼續使用會在初始化階段直接拋出例外。

若你在 Windows上開發，注意路徑分隔符的差異。這個問題在macOS與 Linux 上不會出現。

## 除錯

打開 debug 模式之後，主控台會印出每一次請求的耗時。實測一般查詢在200毫秒以內完成，複雜的聚合查詢可能需要2秒。
