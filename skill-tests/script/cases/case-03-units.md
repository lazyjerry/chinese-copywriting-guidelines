# 開發機規格評測

## 網路與儲存

我家的光纖入屋寬頻有 10Gbps，工作站的 SSD 一共有 20TB。備份用的機械硬碟另外掛了兩顆，單顆容量 8TB，實測循序寫入穩定在 210MB 上下。

系統碟只留 512MB 的 EFI 分割區，其餘全部給根目錄使用。記憶體時脈跑在 3.6GHz，散熱器換成塔扇之後溫度明顯下降。

## 顯示與外觀

螢幕支架可以調整到 90° 的直角，桌面利用率因此提升不少。新款 MacBook Pro 有 15% 的 CPU 效能提升，這個數字是原廠實驗室的結果。

底下兩行刻意寫錯，用來確認度數與百分比的空格會被抓出來：

角度為 90 ° 的角，就是直角。新 MacBook Pro 有 15 % 的 CPU 效能提升。

面板邊框只有 4mm，整機厚度 15mm，收在背包側袋剛剛好。

## 音訊與電力

錄音介面支援 44.1kHz 取樣率，母帶處理時會切到更高的規格。監聽耳機的靈敏度標示 120dB，長時間配戴仍然舒適。

行動電源電量 5000mAh，接上筆電大約可以多撐兩個小時。變壓器輸出 65W，體積比原廠那顆小了一半。

處理器採用 7nm 製程，待機功耗壓得很低。顯示卡的顯示記憶體是 16GiB，跑大型模型時餘裕充足。

## 環境

機房恆溫維持在 25 °C，濕度控制在 45% 到 55% 之間。這個溫度寫法依國際單位制應該保留空格，是給誤報測試用的樣本。

延遲方面，本地端到機房的往返時間量測結果是 100ms，尖峰時段會升到 180ms 左右。
