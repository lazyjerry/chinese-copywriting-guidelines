# 球賽轉播側寫

## 上半場

開賽哨聲響起的那一刻，整座球場的聲量瞬間拉滿。德國隊竟然戰勝了巴西隊！！這個比數在賽前沒有任何一份預測報告寫得出來。

坐在我旁邊的球迷整場都在喊，喊到後來聲音都啞了。德國隊竟然戰勝了巴西隊！！！！！！！！他大概重複了十幾次。

## 中場休息

轉播單位放了一段賽前訪談，主播問到球隊的心理準備。她竟然對你說「喵」？？！！這句是隔壁桌的對話，被麥克風收了進去。

同一段訪談的字幕出現另一種寫法。她竟然對你說「喵」？！？！？？！！排版上同樣不可取。

正確的寫法只留一組。她竟然對你說「喵」？！這樣就夠了，語氣不會因此變弱。

## 下半場

比數拉開之後，場邊的氣氛反而安靜下來。教練換上兩名新人，節奏立刻不一樣了。終場前的那記射門擦柱而出，全場發出一聲嘆息。

## 賽後

記者會上，教練談到球隊這一年的準備過程。他說話很慢，停頓很多。。。這種以句號代替刪節號的寫法應該要被抓出來。

球員的心情也很複雜，，訪談逐字稿裡出現重複的逗號，同樣不該放過。

最後一句留給球迷。謝謝你們！ ！中間隔了一個空格的重複驚嘆號，看起來沒那麼明顯，但仍然是重複標點。

下個賽季再見。
