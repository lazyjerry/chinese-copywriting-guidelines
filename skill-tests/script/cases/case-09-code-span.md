# API 文件片段

## 物件

在 LeanCloud 上，資料儲存是圍繞`AVObject`進行的。這一行的行內程式碼兩側都缺了空格。

正確的寫法是這樣：在 LeanCloud 上，資料儲存是圍繞 `AVObject` 進行的。

半邊有空格、半邊沒有一樣算錯：資料儲存是圍繞 `AVObject`進行的。

反過來也一樣：資料儲存是圍繞`AVObject` 進行的。

## 欄位

每個 `AVObject` 都包含了與 JSON 兼容的 key-value 對應的資料。資料是 schema-free 的，你不需要在每個 `AVObject` 上提前指定存在哪些鍵，只要直接設定對應的 key-value 即可。

## 方法

呼叫`save()`之後，伺服器會回傳更新後的物件。若要指定條件，請改用 `saveIfNotExists()` 這個方法。

刪除單筆資料用`destroy()`，批次刪除請改用 `destroyAll()` 並傳入陣列。

段落開頭直接放程式碼也可以，`AVQuery` 是查詢的入口。

段落結尾同樣可以是程式碼，查詢的入口是 `AVQuery`
