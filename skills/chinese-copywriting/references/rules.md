## 引用參考格式

```text
{規則名稱} L{起始行}-L{結束行}
```

規則名稱與行號之間放一個半形空格，例如 `空格 L16-L90`、`數字使用半形字符 L138-L148`。只涉及單行時寫成 `L38`。

分隔符用空格而不用冒號：半形 `:` 在中文語境違反規則 6，全形 `：` 依規則 4 前後不得留白、讀起來會變成標籤而非引用標記。中文與拉丁字母之間本來就要空格（規則 1），空格分隔剛好同時滿足這條。

## 1. 中英文之間需要增加空格

引用參考 中英文之間需要增加空格 L22-L38

正確：

> 在 LeanCloud 上，數據儲存是圍繞 `AVObject` 進行的。

錯誤：

> 在LeanCloud上，數據儲存是圍繞`AVObject`進行的。

半邊有空格、半邊沒有一樣算錯：

> 在 LeanCloud上，數據儲存是圍繞`AVObject` 進行的。

行內程式碼兩側同樣要空格。完整的正確用法：

> 在 LeanCloud 上，數據儲存是圍繞 `AVObject` 進行的。每個 `AVObject` 都包含了與 JSON 兼容的 key-value 對應的數據。數據是 schema-free 的，你不需要在每個 `AVObject` 上提前指定存在哪些键，只要直接設定對應的 key-value 即可。

**例外**：「豆瓣FM」等產品名詞，按照官方所定義的格式書寫。

## 3. 數字與單位之間需要增加空格

引用參考 數字與單位之間需要增加空格 L52-L74

正確：

> 我家的光纖入屋寬頻有 10 Gbps，SSD 一共有 20 TB。

錯誤：

> 我家的光纖入屋寬頻有 10Gbps，SSD 一共有 20TB。

**例外**：度數與百分比和數字之間不需要增加空格。

正確：

> 角度為 90° 的角，就是直角。

> 新 MacBook Pro 有 15% 的 CPU 性能提升。

錯誤：

> 角度為 90 ° 的角，就是直角。

> 新 MacBook Pro 有 15 % 的 CPU 性能提升。

## 4. 全形標點與其他字符之間不加空格

引用參考 全形標點與其他字符之間不加空格 L76-L86

正確：

> 剛剛買了一部 iPhone，好開心！

錯誤：

> 剛剛買了一部 iPhone ，好開心！

> 剛剛買了一部 iPhone， 好開心！

CSS Text Module Level 4 的 `text-spacing` 和 Microsoft 的 `-ms-text-autospace` 可以自動為中英文之間增加空白，但目前並未普及，macOS、iOS、Windows 的使用者介面也不存在這個特性，所以仍須隨手加空格。

## 5. 不重複使用標點符號

引用參考 不重複使用標點符號 L94-L112

中國大陸的標點符號用法雖然允許重複，但這麼做會破壞句子的美觀性。

正確：

> 德國隊竟然戰勝了巴西隊！

> 她竟然對你說「喵」？！

錯誤：

> 德國隊竟然戰勝了巴西隊！！

> 德國隊竟然戰勝了巴西隊！！！！！！！！

> 她竟然對你說「喵」？？！！

> 她竟然對你說「喵」？！？！？？！！

單一的疑問驚嘆號組合「？！」可以接受。

## 6. 使用全形中文標點

引用參考 使用全形中文標點 L118-L136

正確：

> 嗨！你知道嘛？今天前台的小妹跟我說「喵」了哎！

> 核磁共振成像（NMRI）是什麼原理都不知道？JFGI！

錯誤：

> 嗨! 你知道嘛? 今天前台的小妹跟我說 "喵" 了哎!

> 嗨!你知道嘛?今天前台的小妹跟我說"喵"了哎!

> 核磁共振成像 (NMRI) 是什麼原理都不知道? JFGI!

> 核磁共振成像(NMRI)是什麼原理都不知道?JFGI!

**例外**：中文句子內夾有英文書籍名、報刊名時，不應借用中文書名號，應以英文斜體表示。

## 7. 數字使用半形字符

引用參考 數字使用半形字符 L138-L148

正確：

> 這件蛋糕只賣 1000 元。

錯誤：

> 這件蛋糕只賣 １０００ 元。

**例外**：在設計稿、宣傳海報中出現極少量數字的情形，為方便文字對齊，可以使用全形數字。

## 8. 遇到完整的英文整句、特殊名詞，其內容使用半形標點

引用參考 遇到完整的英文整句、特殊名詞，其內容使用半形標點 L150-L162

正確：

> 賈伯斯那句話是怎麼說的？「Stay hungry, stay foolish.」

> 推薦你閱讀 *Hackers & Painters: Big Ideas from the Computer Age*，非常地有趣。

錯誤：

> 推薦你閱讀《Hackers＆Painters：Big Ideas from the Computer Age》，非常的有趣。

## 9. 專有名詞使用正確的大小寫

引用參考 專有名詞使用正確的大小寫 L166-L198

大小寫相關用法原屬於英文書寫範疇，這裡只對部分易錯用法進行簡述。

正確：

> 使用 GitHub 登錄

> 我們的客戶有 GitHub、Foursquare、Microsoft Corporation、Google、Facebook, Inc.。

錯誤：

> 使用 github 登錄

> 使用 GITHUB 登錄

> 使用 Github 登錄

> 使用 gitHub 登錄

> 我們的客戶有 Github、FourSquare、MicroSoft Corporation、Google、FaceBook, Inc.。

**注意**：當網頁中需要配合整體視覺風格而出現全部大寫或小寫的情形，HTML 中請使用標準的大小寫規範書寫，並通過 `text-transform: uppercase;` 或 `text-transform: lowercase;` 對表現形式進行定義。

## 爭議規則

以下用法略帶個人色彩，無論是否遵循，從語法的角度來講都是**正確**的。預設不套用。

### 11. 超連結之間增加空格

引用參考 超連結之間增加空格 L214-L226

用法：
